# Assignment Requirements

## Required sections

1. Hero
2. Shop / product grid
3. Best-selling combos
4. Bundles
5. Reviews rail

## Platform requirements

- Build on stock Dawn
- Use real Shopify product data
- Make merchant-facing content editable
- Support section and block reordering
- Handle sold-out products
- Handle products without images
- Handle unusually long product titles
- Preserve the visual design
- Improve production quality, accessibility and performance
- Support reduced motion
- Keep code reusable and reviewable

## Deliverables

- Development store URL and password
- GitHub repository with commit history
- Metafield or metaobject definitions
- Build notes
- AI workflow notes
